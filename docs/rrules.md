# Documentation Rules

Effective date: 2026-07-09

## Location

All cross-project research/progress documents should go under:

`/home/923873155/Sem 4 Research/docs`

Project-local docs can still live inside their repo when needed, but any shared report or progress note should also be copied or summarized here.

## File Naming

Every new document must include:

`topic_name_YYYY-MM-DD.md`

Examples:

- `skillllm_v2_research_refresh_2026-07-09.md`
- `skillspan_benchmark_summary_2026-07-09.md`
- `stage2_training_status_2026-07-09.md`

Use lowercase topic names with underscores. Avoid spaces in filenames.

## Exception

This policy file is intentionally named `rrules.md` because it is the fixed documentation rule file requested for the root docs folder.

## Required Evidence

Research reports must not invent results. Claims should be backed by at least one of:

- inspected code
- inspected artifacts
- command output
- generated metrics
- cited research sources

## Report Standard

Every report should include:

- project path
- branch or repo state
- files inspected
- files created or modified
- tests/evaluations run
- metrics before and after, if applicable
- unresolved issues
- exact next commands
