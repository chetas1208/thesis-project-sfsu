# Thesis Missing Administrative Information

Complete these fields in `docs/thesis/main.tex` before SFSU Graduate Studies format check:

- [ ] `\thesisauthor` — legal or consistently formatted preferred name
- [ ] `\thesisadvisor` — committee chair name
- [ ] `\thesiscommittee` — full committee member names
- [ ] `\thesisstudentid` — SF State student ID
- [ ] `\thesissubmissiondate` — degree semester and year (e.g., Fall 2026)
- [ ] Final approved thesis title (if department requires title change)
- [ ] Certification of Approval page — obtain via Adobe Sign workflow per Graduate Studies
- [ ] Confirm whether CS provides an official LaTeX template (currently **not found** in repository)
- [ ] Preliminary format check with Graduate Program Specialist
- [ ] Final accessibility check (headings, alt text, reading order)
- [ ] Library submission via “Submit Scholarly Work” after format approval

Scientific content should **not** use placeholders; only these administrative items remain manual.
