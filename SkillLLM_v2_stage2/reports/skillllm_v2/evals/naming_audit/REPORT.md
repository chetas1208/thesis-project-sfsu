## Verdict: **ADOPT WITH CAVEAT**

The exact string 'SkillGraphLM' (and 'SkillGraph-LM' / 'SkillGraph LM') appears nowhere: no paper title, repository, PyPI/npm package, Hugging Face model/dataset/space, or web page uses it (arXiv, OpenAlex, Crossref, ACL Anthology, GitHub, PyPI, npm, Hugging Face, and general web searches run by two agents on two dates). The stem 'SkillGraph' is however heavily used: several 2026 arXiv papers titled 'SkillGraph' (RL for agents 2605.12039, multi-agent 2604.17503, tool sequencing, dependency-aware retrieval), SkillGraph-Service (arXiv 2605.01582, ESCO/O*NET skill graph for competency-based education, the closest in domain), PyPI and GitHub projects, a Product Hunt career-strategy product 'Skillgraph' (same skill-gap-to-learning problem), and the generic HR-tech term 'skills graph'. The internal name 'SkillLLM' is NOT usable: it resolves to Skill-LLM (Herandi et al. 2024, arXiv 2410.12052), the same task on the same SkillSpan data. A trademark search could not be performed from this host.

Caveats and required actions:

- Use the full title 'SkillGraphLM: Non-Regressive Skill Extraction and Graph-Augmented Learning-Path Intelligence' (no source uses 'Non-Regressive Skill Extraction') on the cover, abstract and in citations, and keep the descriptive subtitle on every public artefact.
- Add one disambiguation sentence in the thesis: SkillGraphLM is unrelated to SkillGraph (Li et al., 2026, RL for LLM agents), SkillGraph-Service (Le, Abel & Laforge, 2026) and Skill-LLM (Herandi et al., 2024); cite the last two as related work.
- Do not publish a PyPI/npm package or Hugging Face repo named plain 'skillgraph' (taken or near-taken); register skillgraphlm early if public release is planned (the exact name is free on PyPI/npm/HF/GitHub on the audit date).
- Run a formal trademark search (USPTO tmsearch, EUIPO eSearch, WIPO) before any commercial use: an unverified aggregator listing shows a pending USPTO application SKILLGRAPHS (serial 99842770, class 35); this audit could not confirm it.
- Keep the internal repository/package name SkillLLM_v2 only as an internal label; do not use 'SkillLLM' in titles or the abstract.
- If the author wants a name with no near-duplicates in the skill-graph field, the lighter alternative audit found no exact or near-name hit for SkillAnchorLM, AnchorPathLM or GapGraphLM; SkillTrellisLM has a crowded stem (Trellis agent-skills tooling). These are candidates only, not endorsed.

Decision rule (fixed before adjudication): adopt = no exact-name collision AND no same-field near-name (shared 'SkillGraph' stem) found; adopt_with_caveat = no exact-name collision in any source but the stem or a near-name is used in the same field, so the name is usable only with an explicit disambiguation; pick_alternative = an exact collision in the same task/field, or a registered mark that would block use. Final risk may exceed the screening risk, never fall below it without an override_reason.

- Trademark registries (USPTO, EUIPO, WIPO) are JS applications and could not be queried; the only trademark record is an unverified aggregator listing. Run a formal search before commercial use.
- Google Scholar and DBLP are bot-protected from this host; OpenAlex, Semantic Scholar (when not rate-limited), Crossref, arXiv and the ACL Anthology bibliography were used instead.
- Search engines are US-only and index only part of the web; absence of a hit is evidence, not proof.
